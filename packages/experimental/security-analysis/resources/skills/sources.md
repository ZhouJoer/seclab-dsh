# Reverse-analysis adaptation sources

These DSH methods and scripts are independently written integrations. No upstream installer, executable, MCP configuration, persistence service or automatic experience writer is included.

DSH consumes immutable assets and structured adapter evidence. ZIP paths do not establish obfuscation; framework matches are candidates. Kotlin Metadata.d2 references do not establish class ownership, and nested-class markers remain intact. URLs do not establish service ownership or reachability. Static observations remain separate from dynamic validation. Item and byte limits preserve incomplete status; no upstream shell pipeline or platform-specific installer is used. Applicable upstream licenses govern their original repositories; this package ships original DSH implementations under its package license.
