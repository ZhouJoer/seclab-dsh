# @deepseek-ai/dsh-experimental-client-ui-security-analysis

[English](README.md) | 中文

## 概述

从原生新建聊天菜单或工作台开始分析。工作区已配置时直接打开空白原生聊天，否则先补充环境配置。新建不会发送消息。侧栏关联会话标题前的盾牌可直达对应工作台，行操作按钮出现时盾牌保持原位。会话顶部可切换聊天和工作台。主会话与任务共享名称，历史会话保留各自名称。

工作区任务直接使用原生文件与搜索工具分析源码。**打开工作区聊天**进入关联会话，其原生文件页可浏览当前工作目录。任务显示工作区路径，不复制或监视整个目录。**添加材料**接受显式上传、粘贴文本和 Host 路径。导入材料与历史材料保留已保存的预览。报告只保留引用的代码片段及其来源位置。通过原生侧栏会话菜单改名。移除任务会停止工作并保留历史证据与报告，可在**已移除任务**中恢复；恢复后保持暂停，直到显式继续。

工具箱支持按已配置的本机或托管 Docker 环境设置安装，也可为适配器指定执行环境。本机安装提供 Host 文件选择器，Docker 安装填写容器内路径。保存前检测安装，完成后通过共用通知提示。检测可能启动已配置的托管容器，不安装软件或拉取镜像。研究方向卡显示总次数、已确认与未验证的工具身份数量及执行状态；展开调用可查看关联证据。

工作台默认打开概览，主要页签为材料、发现、证据和报告。更多中收纳调查、活动、HTTP、实验环境和改进。任务设置包含模块选择、可选上下文与环境控制。手动模块选择使用修订号检查，保存失败时保留草稿并显示错误。

研究动态提供可展开的紧凑技能使用列表，按需读取任务已提交的会话记录，按技能名称合并次数，隐藏未使用的目录项和零计数。模型成功读取与用户显式调用合计为读取次数，失败另列。历史记录不可用时显示缺失状态，并保留已读取的统计。

## 使用

首页选择安全分析后，可直接使用工作区默认值发送。**配置**展开本次任务的环境、封存／解封模式、尝试上限、模块、授权、背景和已检测工具偏好。保存本次配置不会修改工作区默认值；**设为工作区默认**才会更新默认值。配置按钮保存后从**保存本次配置**切换为**取消本次配置**，取消即恢复工作区默认值。收起配置或在表单中按 Escape 丢弃未保存编辑。这些操作都不切换模式。普通聊天需在首次发送前切换模式菜单。准备流程在模型运行前关联一个任务，失败时保留草稿。已有任务保留其配置。首次发送的配置和工具检查只拦截空白会话；后续消息无需等待已隐藏的配置编辑器。可展开配置整行可点，始终显示箭头，并提供键盘焦点。

紧凑进度入口同时跟随项目更新、重连快照和工具活动。运行标记包含活动子任务，并在完成、失败或取消后消失。历史子任务进度通过已授权的 Session 身份读取，不会激活子任务。

**重新开始任务**位于任务顶部的固定操作栏。确认区域和新草稿分别显示任务的实际运行环境与已保存工具偏好；展开偏好即可编辑。工具偏好为空时按需选择工具。确认区域说明保留的材料和设置，列出将复用已保存内容的旧材料，随后打开新会话，将目标填入待发送草稿，并在侧栏选中新会话；开始分析仍需点击发送。取消或 Esc 将焦点返回入口。失败时确认区域保留，允许重试，技术详情单独折叠。[重新开始行为](../security-analysis/README.zh.md#use-this-package)定义保留的设置和清空的上下文。

**解除封印 / 重新封印**位于安全分析工作台标题下方的按钮行，以及工作台标题栏。保存期间按钮禁用；失败时保留原模式，可重试。鼠标悬停或键盘聚焦此按钮可查看当前模式和详细解释。分析设置中不再放置第二个模式控件。

**授权与任务背景**为可选信息。新分析继承工作区默认值。任务设置中的折叠上下文卡片支持当前任务编辑与工作区默认值，折叠会保留未保存输入。第一条真实用户文本填充空任务的目标与自动标题；用户已改名时保留该名称。

选择**保存本任务上下文**用于当前任务，或在同一卡片内选择**保存为工作区默认**，供显示的工作区后续新任务沿用。默认值重启后仍保留，不改动已有任务快照或资源设置。自有代码、受托测试和自建靶场模板仅填充空字段，不自动保存。启用授权声明时，需要填写依据、范围、允许事项和限制；有效期可选并显示本地时区。模型输入预览显示完整内容及其 UTF-8 字节数和配置上限。建议文字精简，正文约 200–400 个汉字。预览和保存不调用模型，校验失败保留草稿。[领域包](../security-analysis/README.zh.md#use-this-package)定义快照持久化与权限检查。

工具卡片分别显示安装检测与专用适配状态，列出支持操作及默认执行环境。安装编辑器保存路径与启动参数；独立的 AI 适配区域保存或恢复环境绑定，不触发探测或启动容器。仅部署配置可查看但不可编辑。状态对应所选绑定及匹配的安装配置，不代表项目授权。

**分析工具箱**提供全部、逆向、Web、IoT 和通用工具筛选，仅用于浏览，不决定任务的分析路线。新建分析的**更多选项**提供可选的会话工具偏好；未保存的修改不影响使用已应用设置开始分析；仅在检查及自动恢复选择期间暂停提交。已有任务保留会话偏好编辑入口。分析进展在已记录的工具活动旁显示保存的选择依据。根据内容选择方法与工具的规则由[领域包](../security-analysis/README.zh.md#use-this-package)定义。

概览中的**检查覆盖**列出执行状态、完成条件、未完成依赖和明确关联的观察，区分清点、实现、失败、不完整以及已采纳的当前静态或运行复核。没有检查的材料和未关联检查的观察仍会显示。**处理受阻**打开现有高级检查表单并定位记录；输入原因后核对为待检查，不启动执行。切换项目清除定位，目标消失时明确提示不可用。覆盖修订与可见记录不匹配时显示等待更新。

从调查链路、发现或依据打开同一源码时，共用带路径、行号和代码的预览；原始输出仍可展开复制。报告修订选择旁的**导出证据包**为已保存修订发起经过认证的 ZIP 下载。[领域包](../security-analysis/README.zh.md#source-snapshots-and-offline-checks)定义内容、排除项、校验和限额。提示仅确认已交给浏览器下载，不表示已成功保存到磁盘；应保留下载完成且通过校验的文件。

新分析需要已保存资源设置或 Host 的 `taskIntake.maxAttempts` 提供工作区尝试次数。缺少次数时，创建页打开工作区资源表单，保存设置前禁用两个创建操作。高级工作台共用相同表单和次数。

开始前可一次多选或分批添加文件；选择清单列出全部文件名，并共用上传额度。拖动助手左边缘，或聚焦分隔条后使用左右方向键，可调整宽度。**展开至整页**和**恢复分栏**保留对话草稿。任务的**计划审批**按钮直接打开已保存的验证计划；存在待批准计划时显示提示。查看操作、影响和清理方式后，选择**批准此版本**，再点击**执行计划**。列表为空时，助手需要先保存验证计划。

审批卡片分别标明待验证内容、预期观察、实际运行位置、影响和清理方式。参数、版本哈希及完整执行记录可展开查看。审批与执行状态分别显示；执行失败后刷新已保存的结果。离线 Python 即使选择本机环境，也在 Linux 容器内运行。它读取 `/input/source` 下的导入快照，不能直接读取本机 Windows 路径，也不能原生加载 Windows DLL。失败计划需要按实际运行环境更正后重新审批；批准本身不会修复缺失文件。手动准备计划仍位于**发现**页。

本机 Python 计划在审批前显示 Host 操作系统、固定的解释器与版本、工作目录和本机权限范围。Windows 本机验证应选择此工具，并提交完整 Python 代码。本机计划使用当前文件，不提供 Docker 隔离。离线计划改为本机执行时，需要新建计划并审批。

在专用 profile 中按顺序组合 `@deepseek-ai/dsh-base`、应用 bundle、`@deepseek-ai/dsh-experimental-security-profile`。Web 还需在最后加入 `@deepseek-ai/dsh-experimental-security-web-profile`。使用 `dsh --profile <name>` 启动。详见[安全分析](../security-analysis/README.zh.md)。

工具箱的**分析脚本**标签展示内置流量、MQTT 和原生进程观察脚本。可搜索名称、用途或依赖，按分类筛选，展开查看分析思路、参数、安装路径、示例、输出和限制。浏览无需选择项目或环境，不检测或执行工具。关联技能向 Agent 提供同一组资源；执行及输出规则见[脚本库](../security-analysis/README.zh.md#use-this-package)。

从左侧栏的**安全分析**打开全页 Dashboard。在对话中，点击顶部或输入框旁的**安全工作台**，会在右侧栏标签中打开同一任务浏览器，同时保留聊天和草稿。右侧栏引导页也提供**安全工作台**入口。所选任务关联当前对话时，右侧工作台隐藏聊天按钮；查看其他任务或使用独立工作台时，保留**打开关联对话**，用于打开关联的原生对话，不会开始或恢复分析。每个标签独立保留任务选择，布局随面板宽度调整；窄窗口使用原生侧栏的全屏模式。工作台展示任务数量、名称与目标搜索以及状态筛选。**新建分析**先选择工作区，再暂存可选的文件、文件夹、文字或宿主路径；点击**保存并进入对话**会保存任务与材料，将目标作为未发送草稿带入 DSH 原生输入框。选择模型、引用文件后再发送即可开始。已有草稿及附件保持不变。**开始分析**则直接保存并发送。**更多选项**可选择环境。发送失败仅重试发送。任务详情默认打开**调查链路**，旁边保留总览、资产、发现、证据和报告；返回证据列表保留搜索条件，已保存的 OSCP 风格报告支持版本与格式选择，修复建议显示在独立卡片中。嵌入式高级工作台会保持一级标签高度稳定，并在独立的动态行中展开二级页面。**分析助手**在右侧展开原生对话；折叠保留草稿，切换任务或离开页面释放会话引用。浏览历史不会创建 Session 或修改任务绑定。没有可访问的协调会话时，**继续分析**显式创建并关联会话。已停止任务需要明确恢复，恢复已移除任务仍保持停止。操作、重连及助手轮次结束后会刷新，也可手动刷新。

**调查链路**连接已保存的材料、检查、研究方向、子任务、观察、发现、验证计划和复核记录。卡片显示标题、摘要和状态。可切换链路图与**列表**，搜索问题或结果，筛选运行中或需要关注的记录，并聚焦某个分支。窄屏初始显示列表。已关联观察默认折叠，点击**展开观察**或搜索时显示。密集层级会自动换成紧凑分栏，避免大量观察把全部卡片缩成难以阅读的纵向长链。每个新研究方向会记录前序方向；旧任务当前方向的首次更新也会补记前序，因此暂停后续查的链路仍然连通。图中只使用已保存的关联：没有关联的历史记录保持独立，缺失的引用会明确提示，不补造节点或连线。

选择记录可查看结果、成立条件和相关工作，再按标题选择关联观察，即可读取保存的原始输出；采集失败或不完整、观察方式及清理信息仍直接显示。标识、哈希和完整记录元数据收进可复制的**技术详情**。已保存的复核属于历史记录，当前结论以发现状态为准。验证计划连接到既有的**计划审批**控制，可继续检查实际影响并批准所展示的版本。

源码文件或目录资产支持在会话工作台清点文件、按行读取和字面文本搜索。证据卡片标记静态观察、离线模拟及设备验证，并显示失败与清理详情。每个研究方向列出已记录的子任务问题、角色、执行状态、返回摘要及主 Agent 对报告的处理决定。展开子任务可查看派工原因、完成条件、证据引用、局限和建议下一步；**查看子会话**打开该一次性任务的原始历史。采纳子任务报告不等于确认发现。没有保存委派记录的方向会提示暂无已记录的子任务；较早的子任务摘要仍保留在高级工作台历史中。

工具箱的**设备**标签打开时读取缓存观测。**检查设备**显式检测所选环境；失败保留上次接口及观测时间。串口卡片显示 COM/PnP 和可取得的 USB 标识，不认证 Tufty、不打开端口。在任务材料中选择 Wi-Fi 或 BLE 和本机环境，点击**分析抓包**或**查看帧**，结果进入既有证据与进度视图。已暂停任务需先恢复，缺少可访问会话的任务需先点击**继续分析**。文件大小直接显示，技术详情保留哈希，原始抓包字节不作为文本呈现。

新建分析中的 **Web 目标** 接受授权站点 origin、路径前缀、IP/CIDR 范围和本机或 Kali/Docker 环境。已有任务也可在资产页登记同类外部 HTTP 目标，无需重建任务；选择新环境会将其加入该任务。请求从所选环境发出，私有身份配置、登录步骤和脱敏仍由 Host 管理。准备计划前先连接分析会话，检查展开后的登录与测试请求，再使用已有审批和执行控件。已使用的审批保留执行结果，不能再次执行。

**请求历史** 按目标、方法、路径和状态筛选。选择请求可读取 Host 分页提供的模板、响应头或文本正文；选择两条可比较所显示的状态和内容。缺失、脱敏、省略或截断的内容不能支持相同结论。**生成重放草稿** 将测试步骤复制到可编辑草稿，不发送请求。**关联发现** 记录 HTTP 步骤及其基线、验证或补充用途，并要求重新独立复核该结论。

任务列表通过一条 Host 目录订阅显示运行中、停止中、已暂停、中断待恢复、待审批、待处理和空闲状态。运行任务也可同时待审批；空闲不代表完成。**恢复任务** 解除暂停，**处理中断** 记录核对结果，**继续分析** 打开或显式创建会话，重新发送 HTTP 请求由新验证计划控制。活动时间线中的证据与发现可打开保存的详情。

## 实现

工具卡片共享适配器操作声明，展示独立依赖、支持的路由及不可用的前置条件。Ghidra 只编辑路由，认证仍归 provider 配置。ADB 可选择 Android 环境。抓包分析分别列出 Python 和 TShark。未绑定工具显示**跟随任务环境**。详见 [Provider 设计](../security-analysis/README.zh.md#provider-design)。

<details>
<summary>实现细节</summary>

此包通过 profile patch 或消息输入框的 dock slot 组合能力，不修改默认 profile 或 agent-loop。浏览器通过生成的 Remote 调用领域服务，文案由双语字典提供。安全工具卡片涵盖 APK 检查、证据分析及其他适配器。在准备和执行阶段显示运行中，结果详情与错误状态仅在结果记录后显示。委派成功的工具回执显示**已派出**；进展视图跟踪子任务已保存的执行状态和报告处理决定。不发布 invariant companion，因为包只有可撤销的组合或 UI 注册，业务状态由领域服务持有。

调查链路是当前 WorkbenchView 的只读投影，与执行时间线共用 Dashboard 既有的项目活动订阅，仅在选择观察时读取制品预览。浏览链路不产生模型轮次或持久关联。审批和执行仍由既有领域方法负责。

根级 `security.resource.actions` Factory 为两种工作台显示方式唯一声明 `security.resource.actions.item`。材料预览、证据详情和调查详情将项目及不可变资源身份交给可选贡献者。[研究适配器](../research-security/README.zh.md)拥有对应按钮；禁用后原预览保持可用。

</details>

## 持久安全项目

任务列表提供行内删除确认、进行中状态和收起退场动画，并支持减少动态效果。普通删除可撤销。“已删除任务”的每行直接提供“恢复分析任务”，操作后停留在当前页面，恢复的任务保持暂停。永久删除入口位于该列表，点击后二次确认即可，且无法撤销。请求失败后保留任务及其操作以便重试。分析摘要和报告使用简体中文，代码标识和路径保持原样。

工具箱打开时显示定义目录，不运行探测。可搜索用途、按标签和工具包筛选，然后检测单个工具或筛选结果。定义表单、JSON 导入预览与工具包导出无需选择项目或聊天。导入冲突需要显式确认，导入不安装软件、不执行命令。可编辑的本机环境保留可执行文件浏览、参数设置、版本检测和恢复默认配置；检测失败保留原安装配置。应用会话工具偏好前检查适配器和依赖；检查失败时自动恢复自动选择并显示原因；若恢复操作也失败，则保留草稿和此前生效的设置，不阻止开始分析。成功应用后禁用通用 Shell 执行；恢复自动选择可重新启用原生工作流。偏好从下一次模型请求生效，在会话释放后清除。参见[采集指南](../../../docs/user/guide/security-analysis.zh.md)。

侧栏安全分析面板无需选择聊天即可列出项目、目标、检查、发现、复核、报告和靶场实例。历史分析页的高级详情提供显式复用本地镜像和构建新镜像操作，两者都保留已有靶场的镜像标识。聊天工作台可登记已启动 Web 目标、应用独立复核和生成修订报告。两个项目视图均直接排版展示已保存的 Markdown 简报及可选发现附表。[Web 指南](../../../docs/user/guide/security-analysis.zh.md#local-web-laboratory) 说明操作流程与当前 provider 限制。

主聊天页在输入框上方保留紧凑的**工具**计数徽标，点击后在原生右侧栏打开**工具与进展**；侧栏关闭时徽标仍实时更新。未关联任务的会话在侧栏显示明确空状态。窗口通过独立且可释放的流跟踪会话选择和项目活动。任务详情保留**工具与进展**标签，用于查看执行时间线。两个时间线入口都按研究方向展示三行：使用工具、当前结论、下一步或阻碍。多轮研究更新同一段；问题改变后返回侦察会形成独立一段。工具名称和次数仅供参考，同名计数合并，不显示执行核实标签；执行失败与输出不完整状态仍保留。展开后分页查看调用详情及证据标题，调用标识和参数收进技术详情。空状态明确区分未保存的记录和聊天摘要。重连恢复所选项目的快照。侧栏只展示信息。原生输入框保留已有停止按钮；暂停整个项目仍属于工作台管理操作。直接在原生输入框中补充或纠正分析方向；暂停的项目需明确恢复后才能继续分析。


**持续改进**页面汇总所有任务在能力、流程、脚本和方法论上的建议，可搜索并按任务、进度筛选。任务详情提供**改进点**和**立即分析改进点**；任务执行中会排队。每项建议在列表中直接显示详情、复制、下载、状态和删除操作。**查看详情**展开引用记录、期望能力和验收方式。来源任务菜单贴近选择按钮，长任务名自动换行，列表在窗口范围内滚动。可复制 Markdown，或下载包含 `TASK.md`、`proposal.json` 和 `result.template.json` 的 ZIP。手动填写实施回执或导入 JSON，检查结果后再明确确认验证。导入的测试声明不会自动验证建议。每项建议按本地时区显示最后更新时间。确认删除后，该共享建议及其实施回执会从所有任务的列表中移除，原始分析轨迹保留；后续分析可能生成类似建议。忽略的建议可以恢复；已验证建议出现新依据时提示复查。

<a id="model-experience"></a>

Dashboard 和报告面板显示已保存成果的报告交付状态。失败或中断时提供**重试生成报告**，并保留已保存成果；成功报告继续在现有版本查看器中展示。紧凑主按钮**立即分析改进点**与导航区分；失败时改为**重新分析改进点**，排队或运行时禁止提交。可操作的状态说明紧邻按钮，技术原因单独折叠，已有建议保持可见。

## 模型体验

### 安全上下文

#### 模型看到的内容

保存并进入对话仅准备可编辑草稿，不调用模型。开始分析会将用户填写的目标作为原生对话消息发送；`security_scope` 由领域服务提供。领域工具把模型可见结果记录在 Session 中。

#### Token 影响

领域工具定义和检索到的证据按配置的输出限额占用上下文。此包不改变 token 统计。

#### KV Cache effect

固定工具定义和工作流指引保持稳定；项目状态通过已记录的工具结果进入上下文。
