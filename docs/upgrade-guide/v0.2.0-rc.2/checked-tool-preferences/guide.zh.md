# 经过检查的工具偏好

[English](guide.md) | 中文

## 变更

应用非空的安全工具偏好时，会先检查所选适配器、执行路由和已安装依赖，再保存。服务会拒绝缺少适配器、提供者不可用或检查失败的选择；偏好编辑器随后自动恢复自动选择并显示原因。检查失败和未保存修改均不阻止开始分析。Ghidra 的就绪状态依赖已导入的程序，无法通过此偏好控件检查。样本和设备访问仍在具体操作时检查。

选择生效期间，禁用 `bash`、`pwsh` 和原生工作流发现。模型直接收到适配器名称及操作列表。同进程调用的 `toolPreferences` 现在返回 Promise；Remote 响应字段不变。

PowerShell 命令保留末尾失败的原生程序退出码，包括有符号 Windows 加载器状态，不再统一变为 `1`。文本渲染器和终端卡片支持负退出码，并报告常见 DLL 加载失败。

## 迁移

1. 在工具设置中配置安装路径、启动参数和适配器环境绑定，然后重新应用选择。
2. 需要通用 Shell 命令或缺少可检查适配器的工具时，使用**恢复自动选择**。
3. 同进程调用 `toolPreferences` 时使用 await。将所有非零 Shell 退出码视为失败，不要仅与 `1` 比较。
