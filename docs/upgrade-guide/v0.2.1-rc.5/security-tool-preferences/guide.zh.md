# 使用辅助 Shell 时保留工具偏好

[English](guide.md) | 中文

## 变更

非空安全工具偏好原先禁用 `bash`、`pwsh` 和原生工作流发现。现在，它在受支持的分析操作中优先使用所选适配器，同时允许按既有角色、模块、任务、沙箱和审批规则执行辅助 Shell 工作。助手必须先报告适配器失败或覆盖范围缺口，再使用其他方法；不得静默更换所选可执行文件或环境。

应用偏好仍会先检查适配器、执行路由和已安装依赖，再保存。检查失败会显示原因并保留此前应用的选择。未保存修改不改变已生效设置。已保存偏好在 Host 重启后恢复，并传给委派子会话。检查与偏好不授予执行权限，也不证明样本或设备已就绪。

## 迁移

1. 辅助文件检查、计算或未覆盖操作需要 Shell 时，保留已保存的选择；无需再为这些动作清除偏好。
2. 保存失败后修正报告的安装或选择问题，再次应用。仅在希望清除偏好时使用**恢复自动选择**。
3. 确认助手在受支持的分析中使用所选适配器，并在选择其他方法前报告失败或不支持的操作。既有任务限制和审批要求仍然生效。
