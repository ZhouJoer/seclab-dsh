# 停用安全工作台的磁盘搜索缓存

[English](guide.md) | 中文

## 变更

每次搜索都在内存中为调用方可见的记录建立索引。修改项目时也无需写入搜索数据库。Host 取得安全数据目录的独占锁后，仅在旧 `search.sqlite` 的完整表结构与工作台索引一致，且没有 SQLite 配套文件时，才会删除它。

## 迁移

1. 如果备份或监控任务依赖工作台持续写入 `search.sqlite`，请移除这一项。继续备份安全日志和制品。
2. 升级 Host 后，搜索一条已知记录。如果目录中仍有 `search.sqlite`，先核对文件归属及其 SQLite 配套文件，再决定如何保留。此前隔离的 `search.sqlite.corrupt-*` 可能包含历史搜索数据，可单独核查。
