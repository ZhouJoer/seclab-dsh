# 第二次调查复核后恢复实验

[English](guide.md) | 中文

## 变更

安全配置的协调者先前可以在每次方向复核后继续调用探索工具。如果同一轮的两次定期复核之间既没有新的完整证据支持已完成的检查，也没有变更调查方向，协调者仍可查阅已有证据、咨询顾问、管理作业、提交命令、发现能力与环境以及加载技能。发现工具和选择模块不代表调查已有进展。通过 SDK 向安全配置重放工具调用的客户端也会遇到此要求。

## 迁移

1. 缺少方法时，通过 `security_capabilities`、`security_environment` 和 `skill` 在现有权限内检查可用选项。用 `security_scope` 读取当前修订号和待完成检查。若已有观测满足判据，通过 `security_command` 提交 `finish`，附上证据 ID 和理由。失败或不完整的观测不满足恢复条件。
2. 若判据仍未满足，提交变更后的 `checkpoint`，在 `summary` 中写明观测结果或尚未测试的对照，在 `reason` 中列出竞争解释的不同预测，在 `next` 中写明区分两者的实验。
3. 确认下一步可在剩余预算内使用项目的探索工具。后续轮次先核对保存的调查方向和待完成检查，再继续实验。
