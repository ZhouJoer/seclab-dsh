# 安全工作区任务

[English](guide.md) | 中文

## 变更

新建分析继承工作区环境并打开空白原生会话，任务可以在第一条用户消息之前存在。保存的记录可包含主 Session 身份与当前工作区材料指针。旧版本使用严格记录校验，无法读取这些新字段。

自定义 Client ISessions 实现必须提供 registerPresentation() 与 renameDisplayTitle()。展示源覆盖业务对象拥有的名称，并保留已关联的空白会话身份；原始 Session 标题保持不变。任务目录现在包含关联会话，供精确导航使用。

## 迁移

1. 同时升级 Host 与 Client。已有任务保持可读并保留当前材料，历史会话不会被重命名。
2. 使用**新建分析**创建关联的原生会话。没有默认环境时先选择工作区环境，再在聊天中输入目标。新建不会发送消息。
3. 通过会话盾牌打开工作台并检查目录材料状态。需要时通过 `workspaceMaterials` 配置采集预算。
4. 升级前备份安全工作台存储。返回旧版本时恢复该备份，不要用旧读取器打开新写入的任务记录。
