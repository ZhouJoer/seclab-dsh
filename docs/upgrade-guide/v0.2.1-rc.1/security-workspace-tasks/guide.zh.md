# 安全工作区任务

[English](guide.md) | 中文

## 变更

新建分析继承工作区环境并打开空白原生会话。首页选择安全分析模式后，首次发送也会在任何模型请求或工具调用前创建并关联任务。缺少配置时阻止发送并保留草稿。普通模式不会自动创建安全任务。任务可以在第一条用户消息之前存在。保存的记录可包含主 Session 身份与当前工作区材料指针。旧版本使用严格记录校验，无法读取这些新字段。

自定义 Client ISessions 实现必须提供 registerPresentation() 与 renameDisplayTitle()。展示源覆盖业务对象拥有的名称，并保留已关联的空白会话身份；原始 Session 标题保持不变。任务目录现在包含关联会话，供精确导航使用。

## 迁移

1. 同时升级 Host 与 Client。已有任务保持可读并保留当前材料，历史会话不会被重命名。
2. 在首页选择安全分析模式，直接使用工作区默认值发送，或展开**配置**保存本次任务设置。只有**设为工作区默认**会更新默认值。取消和恢复操作保留当前模式。**新建分析**创建关联的空白聊天，不发送消息。重新开始沿用当前任务配置及授权有效期。提及 URL 不会登记目标。工作区配置和首次发送配置使用 `security_workspace_intake_v2`；旧域保持原样，不自动导入。按需重新设置工作区默认值，并将显式存储路由改为新域名。
3. 通过会话盾牌打开工作台并检查目录材料状态。需要时通过 `workspaceMaterials` 配置采集预算。
4. 升级前备份安全工作台存储。返回旧版本时恢复该备份，不要用旧读取器打开新写入的任务记录。
